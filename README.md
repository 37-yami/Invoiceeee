# 学生报销管家

拍照/上传票据 → 自动或半自动分类归档 → 一键生成正式报销汇总单(.docx / CSV)。

纯本地、零云服务、零账号、隐私优先:所有数据留在你自己的工作区目录,默认不联网。

## 快速开始

环境:Windows / macOS / Linux,Python 3.11+。

```bash
pip install -r requirements.txt   # 仅 python-docx
python app.py                     # 默认 http://127.0.0.1:8765
```

浏览器打开 <http://127.0.0.1:8765> 即可使用。

- `python app.py --workspace D:\报销管家` 指定工作区(默认在当前目录建 `报销管家工作区/`)
- `python app.py --port 9000` 换端口
- `python app.py --lan` 开放局域网(手机上传,见下)

## 使用流程(三步)

1. **上传**:「上传/待确认」页拖拽或选择图片(手机可直接拍照);可下拉选择类别,不选则按文件名/OCR 自动识别。
2. **确认**:识别不了或字段不全的票据进入待确认列表,修正类别/金额/日期/商户后点「确认归档」,原图自动归档。
3. **汇总**:「票据库」按日期/类别/关键词筛选并勾选 → 「生成汇总单」填报销人信息 → 预览合计 → 生成 docx 或导出 CSV。

## 工作区结构

```
工作区/
├── data.db        # SQLite 索引(不存图片)
├── uploads/       # 上传原图(确认归档后会移走)
├── invoices/      # 归档票据:YYYY-MM/类别/YYYYMMDD_商户_金额_编号.图片
├── exports/       # 生成的汇总单与 CSV
├── logs/app.log   # 操作日志(只记动作与元数据)
└── .trash/        # 回收站(删除的票据原图,不物理删除)
```

类别目录名中的 `/` 替换为 `-`(如 `高铁-铁路`),数据库中仍是原类别。

## 手机上传

1. 电脑与手机连同一 Wi-Fi。
2. 电脑上运行 `python app.py --lan`,记下控制台打印的访问码。
3. 手机浏览器打开控制台显示的地址(如 `http://192.168.1.5:8765`),输入访问码即可上传拍照票据、确认类别。

访问码只在 `--lan` 模式存在;本机 127.0.0.1 访问免验。用完关掉程序即不再对外可见。

## 备份与迁移

直接**复制整个工作区目录**即完成备份;换电脑时把目录拷过去,`python app.py --workspace 路径` 继续用。所有原图都能在 `invoices/` 下按"月份/类别/日期_商户_金额"直接找到。

## 重复检测

同一文件二次上传(内容哈希相同)、发票号相同、或"日期+金额+商户"一致时会标记"疑似重复",可点「强制保留」。

## OCR(可选)

默认不启用 OCR(零重依赖),票据进待确认队列人工确认。如本机装有 OCR 命令行工具,在「设置」页填写命令模板即可启用,例如 tesseract:

```
tesseract {image} stdout -l chi_sim
```

`{image}` 为图片路径占位。OCR 失败自动降级,不影响任何流程。

## 已知限制

- OCR 不内置,需要自行安装并配置命令;自动分类依赖关键词与文件名规则。
- 重复检测为精确匹配(哈希/发票号/日期+金额+商户),不做模糊相似度。
- 单机单人使用,无账号、无同步、无协作。
- 金额精度两位小数;不生成大写金额;汇总单不嵌票据缩略图。
