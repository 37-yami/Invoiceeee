# GUI v2:单界面 + 导航栏改版 计划(2026-11-20)

**用户诉求:** 打开即用,不要首启弹窗选工作区;记录默认放项目路径下;界面参照 DNALLMGUI 排版(左侧导航 + 顶部栏 + 内容区),简洁主题,支持自定义背景图。

## 行为变更
- 启动不再弹窗:工作区解析顺序 `--workspace` > 记忆 > `<项目根>/工作区`(自动创建,不阻塞)
- 换工作区移入「设置」页;顶部栏下拉可快捷切换/打开文件夹
- `.gitignore` 增加 `工作区/`(真实票据永远不进仓库)

## 界面结构(tkinter 扁平化,排版向参考图看齐)
- 顶部栏(深色):应用名 | 工作区下拉(当前/更换…/打开文件夹)
- 左侧导航(深色):概览 / 票据库 / 统计 / 设置,高亮当前页
- 内容区(浅色):四个页面帧切换
  - 概览:欢迎卡片 + 大按钮(导入图片/导入文件夹/拖拽提示)+ 最近导入 + 快捷统计;支持自定义背景图(PIL 压暗处理)
  - 票据库:筛选行 + 表格(多选勾选)+ 编辑面板 + 勾选合计/生成汇总单/导出 CSV(原功能整体迁入)
  - 统计:当前筛选的按类别合计(内嵌页,不再弹窗)
  - 设置:默认报销人/OCR 命令/工作区(切换与打开)/背景图片选择
- 拖拽导入:落点自动切到票据库页
